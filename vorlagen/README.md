## HTML5 UP (Ordner `html5up/`)

Fünf kostenlose Profi-Vorlagen von [HTML5 UP](https://html5up.net):

| Vorlage | Passt gut für |
|---|---|
| `landed` | Dienstleister mit mehreren Unterseiten, dunkles, modernes Design |
| `stellar` | Eine lange Seite mit Abschnitten, z. B. Handwerker, Coaches |
| `forty` | Bildlastige Seiten: Fotografen, Friseure, Restaurants |
| `phantom` | Portfolio mit Kacheln, z. B. für Referenzen |
| `dimension` | Sehr minimale Visitenkarten-Seite |

Zum Ansehen einfach `index.html` im jeweiligen Ordner öffnen.

**Lizenz-Pflicht:** Die Vorlagen stehen unter *Creative Commons Attribution 3.0*. Gewerbliche Nutzung und Änderungen sind erlaubt, aber im Footer muss ein Hinweis stehen, z. B.:

```html

```

Die `LICENSE.txt` in jedem Ordner nicht löschen.
